# Chang-es XXXIX
Code that is used in the paper CHANG-ES XXXIX. Magnetic field structure in edge-on galaxies: Stacking Stokes parameters.
# Paper information
Accepted for publication in Astronomy & Astrophysics Sect. 4. Extragalactic astronomy (2 May 2026).
# File description
## general_functions.py
Low-level functions that are imported into the Jupyter notebooks used for the main analysis.
## run_constatns.py
Variables that are imported into the Jupyter notebooks used for the main analysis (e.g., a list of excluded galaxies).
## plot_constatns.py
Variables (regarding plot sizes, etc.) that are imported into the Jupyter notebooks used for the main analysis.
## df_final.csv
Information about each galaxy.
## data_processing_cubes.ipynb
Processing of the individual Stokes Q & U cubes (including alignment, masking, convolution, scaling).
## data_processing_cube_stacking.ipynb
Stacking of the preprocessed cubes.
